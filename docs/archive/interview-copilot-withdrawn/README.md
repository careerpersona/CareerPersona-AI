# Archived: Real-Time Interview Co-Pilot — original-vision draft

`Real-Time Interview Co-Pilot Locked Blueprint.md` in this directory is the pre-existing, untracked draft document found during the original audit for Premium Feature #6. It predates and is **superseded by** `docs/Real-Time Interview Co-Pilot Blueprint.md` (the verified, audited blueprint), which was itself later marked withdrawn — see `docs/architecture/ADR-Real-Time-Interview-Copilot.md` for the full withdrawal record and `docs/architecture/Architecture-Governance-Retrospective.md` §7 for the governance lesson.

**Why this draft is archived rather than deleted:** it is the only surviving record of the *original*, larger product vision (continuous, ambient, dual-party-aware interview coaching) that the audit and Decision Analysis narrowed away from. It was found during the audit to contain unverified claims about "existing" architecture (a "six AI analyses" characterization where only three real Claude calls existed, and five `session_state` fields that did not exist anywhere in the codebase) — it was never used as a source of truth for implementation, only as historical evidence of what was originally envisioned. Kept for exactly that purpose: if a future feature ever revisits ambient/continuous interview assistance, this is the record of the original ambition to measure against, alongside the ADR's feasibility findings on why it wasn't achievable with any architecture evaluated at the time.

**Not linked from any active roadmap or planning document** — this is historical reference only.
